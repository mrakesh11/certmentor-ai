AWS Security & Compliance Cheatsheet - CCP Exam

Protection Services
AWS Shield P

DDoS protection service that safeguards applications running on AWS.

  • Standard: Automatic protection for all AWS customers
  • Advanced: Enhanced protection + 24/7 support
Remember: "Shield PROTECTS like a superhero against DDoS villains"
AWS WAF P

Web Application Firewall that filters and monitors HTTP/HTTPS requests.

  • Create rules to block common attack patterns
  • Protects against SQL injection and XSS
Remember: "WAF is the bouncer at your web door checking IDs"
Network Firewall P

VPC-level protection against network threats.

  • Stateful, managed firewall service
  • Protects entire VPC from network attacks
Remember: "Network Firewall is your VPC's shield wall"
Encryption & Certificate Services
AWS KMS E

Key Management Service for creating and controlling encryption keys.

  • AWS-managed keys
  • Integrated with many AWS services
Remember: "AWS KMS keeps the KEYS to your encrypted kingdom"
AWS CloudHSM E

Hardware Security Module for regulatory compliance needs.

  • Customer-managed keys
  • Dedicated hardware for compliance requirements
Remember: "HSM = Hardware Security Module where YOU manage the keys"
Certificate Manager E

Provision, manage, and deploy SSL/TLS certificates.

  • Free public certificates for your domains
  • Automatic renewal
Remember: "ACM = Always Certified and Managed SSL certificates"
Compliance Services
AWS Artifact C

Access to AWS compliance reports and agreements.

  • ISO, PCI-DSS, SOC reports
  • Self-service portal for compliance documentation
Remember: "Artifact = Your compliance ART collection"
AWS Config C

Track resource configuration changes and evaluate compliance.

  • Records configuration history
  • Checks resources against compliance rules
Remember: "Config CONFIGures your compliance CONFIGurations"
Detection & Monitoring Services
GuardDuty D

Threat detection service that continuously monitors for malicious activity.

  • Analyzes VPC, DNS, and CloudTrail logs
  • Uses ML to identify suspicious behavior
Remember: "GuardDuty is your AWS security GUARD on DUTY"
Inspector D

Automated vulnerability assessment service.

  • Scans EC2, ECR images, and Lambda functions
  • Finds software vulnerabilities and network exposure
Remember: "Inspector INSPECTS your services for vulnerabilities"
Macie D

Data security service that uses ML to discover sensitive data.

  • Discovers PII and sensitive data in S3 buckets
  • Alerts on potential data security risks
Remember: "Macie TRACES your sensitive data whereabouts"
Tracking & Logging Services
CloudTrail T

API activity tracking for governance and auditing.

  • Records all AWS account activity
  • Who did what, when, and from where
Remember: "CloudTrail leaves a TRAIL of user activity in the cloud"
Security Management Services
Security Hub M

Central place to view and manage security alerts across accounts.

  • Aggregates findings from multiple AWS services
  • Conducts continuous security checks
Remember: "Security Hub is your security command CENTER"
Amazon Detective M

Analyzes and visualizes security data to identify root causes.

  • Investigates suspicious activities
  • Uses ML to analyze events over time
Remember: "Detective DETECTS the root cause of security issues"
Firewall Manager M

Centrally configure and manage firewall rules across accounts.

  • Manages WAF, Shield, and Network Firewall
  • Works across entire AWS Organizations
Remember: "Firewall Manager MANAGES all your firewalls from one place"
IAM Access Analyzer M

Identifies resources shared with external entities.

  • Helps identify unintended access to resources
  • Monitors for overly permissive policies
Remember: "Access Analyzer ANALYZES who can ACCESS your resources"
AWS Abuse M

Process to report abusive or illegal use of AWS resources.

  • Report suspected abuse
  • AWS investigates reported resources
Remember: "AWS Abuse stops ABUSIVE resource usage"

Root User Privileges - CRITICAL TO REMEMBER

Only the root user can:

  • Change account settings
  • Close your AWS account
  • Change or cancel AWS Support plan
  • Register as seller in Reserved Instance Marketplace
Remember with "CCRS": Close account, Change settings, Reserved Instance seller, Support plan changes

Security Services Memory Aid: "PECDTM"

Protection (Shield, WAF, Network Firewall)
Encryption (KMS, CloudHSM, Certificate Manager)
Compliance (Artifact, Config)
Detection (GuardDuty, Inspector, Macie)
Tracking (CloudTrail)
Management (Security Hub, Detective, Firewall Manager, Access Analyzer)
