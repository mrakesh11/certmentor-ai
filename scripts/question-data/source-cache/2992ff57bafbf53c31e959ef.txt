 Migration and Transfer 
 AWS DataSync 
 AWS DataSync
 Simplify and accelerate secure data migrations and transfers
 Get started with DataSync 
 Learn more about DataSync 
 Benefits
 Secure, high-performance migration and transfers 
 Quickly move data to AWS with encryption in transit and end-to-end data integrity validation. 
 Scale to any dataset size 
 Migrate petabytes of data with support for virtually unlimited files and folders. 
 Connect any data source 
 Transfer data from on-premises storage, other cloud providers, and AWS storage services through a single solution. 
 Simple transfer management 
 Control data movement with bandwidth throttling, scheduling, filtering, and comprehensive monitoring. 
 Use cases
 Migrate your data
 Quickly migrate large datasets to AWS. Your data is secure with in-flight encryption and end-to-end data validation.
 Protect your data
 Securely replicate your data into AWS object and file storage services, including Amazon S3, Amazon EFS, and Amazon FSx.
 Archive your cold data
 Free up on-premises storage by moving data directly to cost-effective Amazon S3 Glacier archive storage classes. 
 Accelerate your hybrid and multicloud workloads
 Drive data pipelines with seamless data movement between 
 on-premises storage, other clouds, and AWS.
