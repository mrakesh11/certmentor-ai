 Why DMS?
 DMS implements a comprehensive security framework that safeguards data throughout the migration process using IAM policies, SSL/TLS encryption, and AWS Secrets Manager credential management. Network controls and monitoring tools provide access restriction and real-time visibility. To minimize operational disruption to applications, DMS keeps source systems fully operational until the migration is complete. DMS enhances resilience through Multi-AZ redundancy and checkpoint-based recovery capabilities. Zero data loss and data accuracy are maintained through a data validation processes, while data re-synchronization resolves any discrepancies between databases. DMS offers cost-effective migrations through hourly pricing and serverless scaling that reduces unused capacity to a minimum.

 Use cases
 Move to managed databases 
 Migrate from legacy or on-premises databases to managed cloud services through a simplified migration process, removing undifferentiated database management tasks.
 Modernize to an open source and/or cloud-native database 
 Modernize to reduce costs and enhance availability, disaster recovery, and reliability, which enables faster innovation and more efficient operations. Accelerate database migrations by combining rule-based schema conversions with generative AI-assisted code conversions.
 Re-host your on-premises database on Amazon EC2 
 Start your cloud journey by re-hosting your databases on Amazon EC2 Dedicated Hosts or Bare Metal. Maintain your existing operational model while benefiting from cloud scalability and flexibility. Retain full access to the underlying OS.
