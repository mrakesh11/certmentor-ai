 Introducing Organizations
 AWS Organizations enables central governance and consistent management of your AWS resources across multiple accounts and AWS services. Learn how you can organize AWS accounts based on business needs, apply security, regulatory, and budgetary controls while simplifying billing and enabling cost-saving measures in your environment.

 Use cases
 Create AWS accounts at scale 
 Create and manage AWS accounts via console or programmatically and add them to logical groups for security policy application based on common security requirements
 Learn more about creating accounts in an organization » 
 Ensure access to designated resources 
 Apply service control policies and resource control policies to allow only user actions that meet your security and compliance requirements.
 Learn more about authorization policies » 
 Share common resources across accounts 
 More easily share central resources, software applications, directories, and services within your organization.
 Learn more about sharing your AWS resources » 
 Centralize cloud operations, security, and compliance across multiple accounts 
 Integrate with security and compliance services such as IAM, AWS Security Hub, AWS Control Tower, Amazon GuardDuty, AWS Audit Manager, etc to centralize cloud and security operations. Designate delegated administrators to manage the security services for flexibility and ownership by individual teams.
 Optimize cloud spending with centralized cost management & billing 
 Consolidate billing across all member accounts to unlock volume discounts and shared savings benefits. Gain deep visibility into spending patterns and efficiently manage costs across your entire AWS estate through integrations with AWS Cost Explorer, AWS Cost Optimization Hub, AWS Budgets, and other services, along with enforced tag policies. For environments with multiple AWS Organizations, use Billing Transfer to centrally manage bills and costs across your organizations.
