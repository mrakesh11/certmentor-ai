 Why WorkSpaces applications?
 Amazon WorkSpaces applications (formerly AppStream 2.0) offers a fully managed solution to deliver software-as-a-service (SaaS) and web-based applications and transform desktop applications into cloud-based services without code changes. It enables global scalability without infrastructure management and supports multi-session capabilities , optimizing resource use and costs across various user types. WorkSpaces applications also delivers non-persistent virtual desktops, providing users with a fresh, secure environment at every sign-in, with multi-session support, broad instance type selection, and automatic scaling based on user demand.
 These features now extend to AI agents with WorkSpaces applications, bridging agentic AI to the desktop applications enterprises already run, giving both people and agents secure, scalable application access from a single service.
 Benefits
 Reduce costs and accelerate time to market 
 Allows ISVs to convert desktop applications to Software-as-a-Service (SaaS) delivery without the expense and time required to rewrite code. Share desktop pools across groups of users, scaling capacity up or down based on demand. Optimize costs through pay-per-use resource consumption and customized storage and desktop configurations. 
 Support a wide range of users 
 Select from a range of compute, memory, and storage options. 
 Reduce downtime 
 Leverage a fully managed application streaming service, financially backed by a 99.9% uptime SLA. 
 Empower remote workers 
 React quickly to changing conditions with secure access to applications from anywhere, while auto-scaling to avoid overprovisioning. 
 Enable AI agents to take action 
 Enable AI agents to interact with your desktop applications the same way users do with agentic capabilities for WorkSpaces 
 Use cases
 Convert desktop applications to SaaS 
 Convert desktop applications to SaaS or web-based delivery without rewrites, special hardware, or device installs; ideal for training and software trials. 
 Stream your desktop applications 
 Stream desktop applications to users and AI agents , each in their own isolated sessions, governed by the same policies and security controls, without rewrites, special hardware, or device installs.
 Learning environments 
 Enable online learning over slow network conditions with easy, reliable access to applications and resources. 
 GPU-powered performance for graphics-intensive applications 
 Stream professional graphics applications like CAD/CAM, 3D modeling, GIS, and video editing on the latest NVIDIA Blackwell GPUs. Scales automatically, with no GPU hardware to manage.
