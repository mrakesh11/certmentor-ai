 What is AWS Backup?
 AWS Backup is a fully managed service that centralizes and automates data protection across AWS services and hybrid workloads. It provides core data protection features, ransomware recovery capabilities, and compliance insights and analytics for data protection policies and operations. AWS Backup offers a cost-effective, policy-based service with features that simplify data protection at exabyte scale across your AWS estate.
 Play 
 Benefits of AWS Backup
 Simplify data protection of application resources on AWS and hybrid services 
 Centralize backup and recovery with a fully managed, policy-based service. 
 Build a foundation for disaster recovery and business continuity 
 Back up across different AWS Regions and accounts. Perform automatic restore testing and validation of backups. 
 Protect and recover from ransomware and account compromise 
 Create immutable backups, scan backups for malware, and use logically air-gapped vaults as part of a defense in depth strategy. 
 Govern data protection compliance 
 Monitor, audit, and report on data protection policies and operations using real-time analytics and insights. 
 Use cases
 Cloud-native backup
 Back up key data stores, such as your buckets, volumes, databases, and file systems, across AWS services.

 Centralize data protection management for your applications running in hybrid environments, such as VMware workloads and AWS Storage Gateway volumes.
