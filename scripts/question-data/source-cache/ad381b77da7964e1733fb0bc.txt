 What is Amazon EventBridge?
 Amazon EventBridge is a serverless event broker that makes it easier to build event-driven applications at scale using events generated from your applications, integrated SaaS applications, and AWS services. Platform teams get centralized event routing across all AWS accounts in an organization with governance, observability, and ordering guarantees out of the box. Application developers get simplified subscriptions that combine filtering, target configuration, and retry policies in a single resource. With support for tens of thousands of subscribers per bus, up to 365 days of event retention, and multiple event formats including JSON, Avro, Protobuf, and Cloud Events, Amazon EventBridge reduces integration overhead so teams can ship faster. 
 Benefits of EventBridge
 Build event-driven applications with ease 
 Build loosely coupled, event-driven architectures with simplified event routing to help you deploy new features faster. 
 Share an event bus across your organization 
 Share an event bus across multiple accounts in your AWS Organization through AWS Resource Access Manager, eliminating complex cross-account routing. 
 Order events where sequence matters 
 Provide guaranteed ordering of events for applications where the ordering is critical and mix ordered and unordered events on the same event bus. 
 Connect AWS services with less custom integration code 
 Connect AWS services, software-as-a-service (SaaS) applications, and custom applications as event producers to launch workflows and create integrations without custom code or managing and provisioning servers.

 Use cases
 Increase developer agility 
 Remove the need to coordinate across service teams with decoupled microservices using AWS, SaaS apps, or your own custom apps.
 Monitor and audit applications 
 Monitor and audit your AWS environments, and respond to operational changes in your applications in real time to prevent infrastructure vulnerabilities.
 Extend functionality with SaaS integrations 
 Connect your applications to other SaaS applications by sending a custom event to EventBridge, and then send it through API destinations such Shopify and Zendesk CRM. 
 Make business events available across the organization 
 Route business events across teams and accounts so more services can react to them, reducing coordination between teams and enabling you to derive more business value.
