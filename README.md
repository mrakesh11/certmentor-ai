# certmentor-ai

CertMentor AI helps learners prepare for professional certifications across technologies like AWS, Salesforce, and ServiceNow. It brings together study materials, practice exams, flashcards, and AI-powered explanations to make learning simpler, more interactive, and effective.

This repository currently ships the **AWS Certified Cloud Practitioner (CLF-C02)** learning workspace.

---

## Features

- **Dashboard** — exam progress, per-domain coverage, "what to study next", and the Well-Architected architecture gallery.
- **Guided learning** — topic-by-topic lessons (`/learn`) with graded practice questions and curated architecture diagrams.
- **Practice questions** — standard, weakness-focused, and timed exam modes with a score report.
- **Flashcards** — spaced practice over the question bank.
- **Cheat sheets** — static reference sheets served from `public/cheatsheets`.
- **CloudMentor AI** — a floating study assistant that streams answers from a locally running [Ollama](https://ollama.com) instance (default `http://localhost:11434`); no API keys are involved.
- **Theming** — light / dark / system preference with persistence.
- **Offline-ready** — installable PWA (service worker generated by `vite-plugin-pwa`).

## Getting started

### Prerequisites

- Node.js 20+
- (Optional, for CloudMentor AI) [Ollama](https://ollama.com) running locally with a model pulled, e.g. `ollama pull llama3.2`

### Install and run

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
```

### Available scripts (run from `frontend/`)

| Script | Purpose |
| --- | --- |
| `npm run dev` | Start the Vite dev server with HMR |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
| `npm run test` | Run the Vitest suite |
| `npm run questions:audit` | Audit the raw question bank |
| `npm run questions:enrich` | Enrich questions with references/explanations |
| `npm run questions:verify` | Verify verified-answer coverage |
| `npm run questions:manifest` | Rebuild `learning-manifest.json` |
| `npm run questions:domains` | Rebuild `question-domains.json` |

## Change Log

### 2026-10-15 — UI scaling, theme toggle & bug fixes

**Author:** Pabolu Vineeth

**Theme & navigation**
- Rebuilt the theme control as a compact icon button: an inline SVG sun in dark mode and moon in light mode, with a cross-fade + rotate transition and an accessible `aria-label` / `title`. Replaced the previous three-option light/dark/system selector.
- Toggle uses the applied theme plus `setPreference`, committing an explicit light or dark choice on click.

**Responsive scaling**
- Added a fluid root `font-size` in `src/styles/base.css` so the whole interface (type, spacing, navigation, layout) scales with the viewport like a proportional zoom. Bounds are expressed in `rem` so the browser's base font-size preference is still honoured.
- Converted structural `px` to `rem` across design tokens and stylesheets: `tokens.css` (radii, `--content-max`, `--content-narrow`, `--nav-height`), `App.css`, `components.css`, `Dashboard.css`, `PracticeQuestions.css`, `CheatsheetViewer.css`, `Flashcards.css`, and `CloudMentor.css`.
- Tuned the scale curve so headings stay proportionate on large displays and body copy never drops below the 15px baseline (`clamp(1rem, 0.9375rem + 0.15vw, 1.0625rem)`).
- Left the architecture-diagram illustrations (inline `px`, `VPCDiagram.css`) untouched so fixed artwork doesn't break.

**Bug fixes**
- `src/lib/progress.js` — wrapped `saveProgress` writes in `try/catch` so a failed `localStorage` write (quota exceeded / private mode) can no longer throw out of grading.
- `src/pages/Dashboard.jsx` — fixed per-domain coverage always showing `0 of N attempted` by passing loaded progress to `domainProgress()`.
- `src/lib/ollama.js` — streaming now buffers partial NDJSON lines between network chunks (no more dropped tokens) and surfaces `error` frames from Ollama.
- `src/components/CloudMentor.jsx` — the **Retry** button now re-sends the last user message (previously a silent no-op after an error), the empty assistant placeholder is dropped on failure, and the focus timer is cleaned up.
- `src/pages/PracticeQuestions.jsx` — the exam countdown now commits the on-screen answer before auto-submitting; removed a hint that leaked the number of correct answers; removed a duplicate active-set build.
- `src/pages/TopicLesson.jsx` — session state now resets when navigating between topics (React Router reuses the component instance).
- `src/components/CloudMentor.css` — the chat panel reserves the navbar height so its header no longer hides behind the fixed nav on short viewports.

**Quality**
- Added a regression test for failing storage writes in `src/lib/__tests__/progress.test.js`.
- Verified: `npm run lint` clean, `npm run test` 201 passed (13 files), `npm run build` succeeds.
