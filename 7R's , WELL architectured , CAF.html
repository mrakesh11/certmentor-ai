7 R's of Migration

Migration in AWS: The process of moving applications, data, and workloads from on-premises or existing cloud environments to the AWS Cloud, following defined migration strategies.
Mnemonic: "Really Reliable Refactoring Requires Rethinking Retirement Repurchasing"
Strategy Definition Key Characteristics When to Use
Rehost
("Lift and Shift")		 Migrating applications without changes • Fastest migration option
• Minimal application changes
• Reduced complexity
• Often first step in cloud journey 		• Legacy migrations
• Conservative cloud strategy
• When time constraints exist
• Large-scale migrations
• EC2 VM Import/Export
Replatform
("Lift, Tinker, and Shift")		 Making targeted optimizations while keeping core architecture • Moderate changes
• Better cloud optimization
• Reduced operational overhead
• Some cloud-native benefits 		• Database migrations to RDS
• Containerizing applications
• Automating key processes
• RDS Elastic Beanstalk
Refactor / Re-architect Reimagining application architecture using cloud-native capabilities • Substantial changes
• Maximum cloud benefits
• Highest long-term value
• Most complex option 		• Business needs scale or performance
• Adding new features difficult in legacy
• Addressing technical debt
• Lambda DynamoDB API Gateway
Repurchase
("Drop and Shop")		 Switching to different products, typically SaaS • Vendor product switch
• Eliminates legacy maintenance
• Often involves licensing changes
• Potential business process changes 		• Moving from on-prem to SaaS
• End-of-life products
• When vendor support ending
• SaaS offerings AWS Marketplace
Retain
("Revisit")		 Keeping applications in source environment • No immediate migration
• Keep applications as-is
• Often temporary decision
• Part of phased approach 		• Critical legacy systems
• Applications requiring major refactoring
• Compliance/regulatory concerns
• Applications planned for retirement
Retire Removing applications no longer needed • Decommissioning
• Cost savings focus
• Reducing security risks
• Resource consolidation 		• Redundant applications
• Low business value systems
• Obsolete technology
• Data can be archived in S3 Glacier
Relocate
("Hypervisor-level migration")		 Moving infrastructure without changing architecture • VMware-based
• No application changes
• Reuses existing investments
• Hybrid cloud enabler 		• VMware environments
• Large VMware footprint
• Minimizing business disruption
• VMware Cloud on AWS

AWS Migration Tools and Services

Service Purpose Key Features
AWS Migration Hub Single location to track migrations • Centralized view of migration progress
• Integrates with other migration tools
• Visualizes application status
Application Discovery Service Discovers on-premises applications • Agentless and agent-based discovery
• Server utilization data
• Application dependency mapping
Database Migration Service (DMS) Migrates databases to AWS • Supports homogeneous and heterogeneous migrations
• Minimal downtime
• Continuous data replication
Server Migration Service (SMS) Migrates on-premises servers • Automates server migrations
• Incremental replication
• Supports VMware, Hyper-V, and physical servers
Exam Tip: For the CCP exam, know what each "R" stands for and identify when each strategy is most appropriate to use. Remember that Rehost is the quickest but least optimized, while Refactor provides the most cloud benefits but requires the most effort and time.

AWS Well-Architected Tool

A free service that helps you review your architectures against AWS best practices and gives guidance on making improvements.
• Workload reviews against the 6 pillars
• Improvement plans with step-by-step guidance
• Milestone tracking to measure progress
• Risk identification in architecture decisions
• Governance across organization
• Best practice sharing with stakeholders
Exam Tip: For the exam, focus on the primary goal of each pillar, understand which services align with each pillar, and know the design principles associated with each. Pay special attention to the newer Sustainability pillar, as it was added most recently.
