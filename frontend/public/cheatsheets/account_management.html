AWS CCP Exam Cheatsheet

📊 Account Best Practices

Organizations: Manage multiple AWS accounts from a single place
Key features: Consolidated billing, hierarchical organization with OUs (Organizational Units), centralized compliance policy management
Exam focus: Know that Organizations provides consolidated billing and lets you apply policies across multiple accounts
Think: "One Organization to Rule Them All" - centralized management for multiple accounts
SCP (Service Control Policies): Restrict account permissions
Important: SCPs are applied at the organization, OU, or account level and define maximum permissions (they don't grant permissions)
Exam focus: Understand SCPs restrict what actions accounts can perform, even for the root user
SCP = Security Control Policies - they control what services can be used
AWS Control Tower: Easy setup of multi-account environments with best practices
Features: Account factory for standardized provisioning, guardrails (preventive/detective controls), dashboard for visibility
Exam focus: Know it helps set up and govern a secure, compliant multi-account AWS environment
Think of an actual control tower - provides visibility and control over multiple accounts
Tags & Cost Allocation Tags: Label resources for management and detailed billing
Types: User-defined tags (created by you), AWS-generated tags (created by AWS). Must be activated in Billing console to appear in cost reports.
Exam focus: Know that tags need to be activated as cost allocation tags before they appear in billing reports
Tags = T.A.G.S = Track And Group Spending
IAM Best Practices:
  • MFA (Multi-Factor Authentication) - uses a second device to verify identity
  • Least-privilege principle - grant only permissions needed
  • Strong password policy - enforce complexity requirements
  • Regular password rotation - change passwords periodically
  • Use IAM roles for EC2 instead of storing credentials
  • Use IAM user groups to assign permissions to multiple users
Exam focus: The CCP exam heavily tests IAM best practices, especially related to security
Remember "MLP-R" - MFA, Least-privilege, Password policy, Rotation
AWS Config: Records resource configurations and compliance
Features: Resource inventory, configuration history, configuration change notification, compliance rules and auditing
Exam focus: Understand Config's role in tracking resource changes and evaluating compliance
Config = Configuration + Compliance Guarantee
CloudFormation: Deploy infrastructure as code across accounts/regions
Key components: Templates (JSON/YAML), Stacks (resources created), StackSets (deploy across regions/accounts)
Exam focus: Know it's for automating infrastructure deployment and ensuring consistency
Think: "Form clouds" - it forms your AWS infrastructure
Trusted Advisor: Provides recommendations for best practices
Five categories checked: Cost Optimization, Performance, Security, Fault Tolerance, Service Limits
Exam focus: Remember the five categories and that different support plans get different levels of advisor checks
Like having a trusted AWS expert advisor on your team
Logging Best Practices:
  • Send Service Logs to S3 or CloudWatch - for detailed operational analysis
  • Store Access Logs centrally - track who accessed what resources
  • Use CloudTrail to record API calls - enabled by default for 90 days, can be configured for permanent storage
Exam focus: Know which service logs what: CloudTrail logs API calls, S3 Access Logs track object access, etc.
"SAC" = Service logs, Access logs, CloudTrail
Compromised Account Steps:
  • Change root password and enable MFA immediately
  • Delete and rotate all passwords/keys/tokens
  • Contact AWS support via Support Center
  • Check CloudTrail for unauthorized activity
  • Review billing for unexpected charges
Exam focus: Understand the immediate steps needed to contain a security breach
"CRC" = Change, Rotate, Contact
AWS Service Catalog: Pre-defined resources for users created by admins
Benefits: Standardization, self-service provisioning, centralized control, and versioning of approved resources
Exam focus: Understand it allows admins to create and manage approved services for users
Think: "Shopping catalog" for approved AWS resources

💰 Billing and Costing Tools

AWS Compute Optimizer: Recommends optimal resource configurations
Analyzes: EC2 instances, Auto Scaling groups, EBS volumes, Lambda functions, and more to find optimal AWS resource configurations
Exam focus: Know it uses machine learning to analyze patterns and provide cost-saving recommendations
CO = Cost Optimization - analyzes usage and recommends savings
AWS Pricing Calculator: Estimates cost of services
Features: Create estimates for specific use cases, compare different instance types/regions, share estimates with others via URL
Exam focus: Know this is the tool to estimate AWS costs before deployment
The "Price is Right" tool - helps predict costs before deploying
AWS Billing Dashboard: High-level overview + free tier usage
Shows: Month-to-date spend, forecasted spend, free tier usage tracking, service breakdown, top services by spend
Exam focus: Know it's where to find basic billing information and free tier usage status
Your financial "dashboard" - shows costs at a glance
Cost Allocation Tags: Tag resources for detailed cost reports
Types: AWS-generated (aws:) and user-defined (user:) tags. Must be activated in billing console before they appear in reports.
Exam focus: Remember tags must be explicitly activated as cost allocation tags to see them in billing reports
CAT = Categorize All Transactions
Cost and Usage Reports: Most comprehensive billing dataset
Features: Most detailed cost data available, can break down to hourly level, includes resource IDs, tags, and pricing details
Exam focus: Know this provides the most granular level of AWS cost and usage data available
CUR = Complete Usage Record - most detailed billing info available
Cost Explorer: Visualize, understand and forecast costs
Features: Interactive graphs, cost forecasting up to 12 months, granular filtering (service, account, tag, etc.), savings recommendations
Exam focus: Understand it provides visualization tools for analyzing past costs and forecasting future spending
Think: "Exploring" your costs with visual graphs and forecasts
Billing Alarms: Set in us-east-1 region for overall/per-service billing alerts
Important: Must be created in the us-east-1 (N. Virginia) region only, uses CloudWatch alarms, monitors estimated charges
Exam focus: Remember billing alarms must be set in us-east-1 regardless of where your resources are
Remember "East Coast Money" - billing alarms are only in us-east-1
AWS Budgets: Advanced cost tracking with customizable alerts
Types: Cost budgets, Usage budgets, Reservation budgets (RI tracking), Savings Plans budgets
Exam focus: Know Budgets is more advanced than billing alarms and allows for actions when thresholds are exceeded
Budgets = Better Understanding & Detailed Governance of Expenses Track & Savings
Savings Plans: Flexible pricing model for long-term savings
Types: Compute Savings Plans (most flexible, any region/family/size/OS), EC2 Instance Savings Plans (specific family in region), SageMaker Savings Plans
Exam focus: Understand it's a flexible alternative to Reserved Instances with 1-3 year commitments
SP = Save Plenty - commitment-based discount program
Cost Anomaly Detection: Uses ML to identify unusual spending
Features: Creates spending baselines, detects anomalies using ML, provides root cause analysis, sends alerts
Exam focus: Know it automatically detects unusual spending patterns using machine learning
CAD = Catches Abnormal Disbursements - finds strange spending patterns
Service Quotas: Alerts when approaching service limits
Features: View default quotas, request increases, set CloudWatch alarms to track usage against limits
Exam focus: Understand it helps manage service limits and avoid hitting them unexpectedly
SQ = Safety Quantities - prevents hitting service limits
Exam Tip: For the AWS Certified Cloud Practitioner exam, focus on understanding when to use each service rather than how to implement them. Know the basic purpose of each service and which ones work together.
Memory Tip: Group these services by function:
  • Security: IAM, MFA, SCP, CloudTrail
  • Cost Management: Tags, Cost Explorer, Budgets, Savings Plans, Compute Optimizer
  • Monitoring: CloudTrail, Trusted Advisor, Billing Alarms, Cost Anomaly Detection
  • Governance: Control Tower, Config, Service Catalog
  • Organization: Organizations, CloudFormation
CCP Exam Strategy: The CCP exam frequently asks scenario-based questions about which service to use for a specific need. For example, "A company wants to identify unusual spending patterns automatically" (Answer: Cost Anomaly Detection).
