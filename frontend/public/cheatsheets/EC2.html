AWS EC2 Study Guide for Cloud Practitioner

🖥️ What is Amazon EC2?

Amazon Elastic Compute Cloud (EC2) is a web service that provides resizable compute capacity in the cloud. It's like having virtual servers in AWS's data centers.

Key Concept: EC2 allows you to provision and scale computing resources on-demand without investing in hardware upfront.

Core Concepts of EC2:

  • Instances: Virtual servers you can provision with various configurations
  • AMI (Amazon Machine Image): Templates containing software configurations (OS, application server, applications)
  • Instance Types: Different CPU, memory, storage, and networking capacity configurations
  • Security Groups: Virtual firewalls that control traffic to your instances
  • Key Pairs: Secure login credentials for your instances

Exam Tip:

Questions often ask which option is most cost-effective for specific scenarios. Remember:

  • If workload is temporary or unpredictable → On-Demand
  • If workload is stable/predictable for 1+ years → Reserved
  • If workload is flexible in timing and can handle interruptions → Spot
  • If you have specific licensing or compliance needs → Dedicated

🔄 How EC2 Connects with Other AWS Services

EC2 + S3

EC2 instances can store and retrieve data from S3 buckets to persist data beyond instance termination.

Example: Web servers on EC2 storing user uploads in S3

EC2 + EBS

Elastic Block Store provides persistent block-level storage volumes for EC2 instances.

Example: Database servers needing persistent storage

EC2 + ELB

Elastic Load Balancing distributes incoming traffic across multiple EC2 instances for high availability.

Example: Web application scaling to handle varying loads

EC2 + Auto Scaling

Auto Scaling automatically adjusts EC2 capacity based on demand.

Example: Automatically scaling out when traffic increases

EC2 + VPC

EC2 instances are launched within a Virtual Private Cloud for network isolation.

Example: Creating public and private subnets for different tiers

EC2 + IAM

Identity and Access Management controls who can access and manage EC2 resources.

Example: Creating roles for EC2 to access other AWS services

EC2 + CloudWatch

CloudWatch monitors EC2 instances and sets alarms based on metrics.

Example: Monitoring CPU utilization and triggering alerts

EC2 + SNS

Simple Notification Service can send notifications based on EC2 events.

Example: Getting alerts when instances terminate

Family Use Case Exam Tips
General Purpose (T, M) Web servers, development environments, small databases T instances are burstable (CPU credits), M instances provide balanced resources
Compute Optimized (C) Batch processing, scientific modeling, gaming servers, high-performance web servers High performance processors, best price-to-compute performance
Memory Optimized (R, X, z) Memory-intensive applications, database servers, big data processing engines Fast performance for workloads processing large datasets in memory
Storage Optimized (D, H, I) Distributed file systems, data warehousing, high-frequency OLTP systems Designed for high sequential read/write access to large datasets
Accelerated Computing (P, G, F) Machine learning, graphics processing, gaming, high-performance computing Use hardware accelerators (co-processors) to perform functions like graphics processing

Popular Instance Types to Remember:

  • t2.micro - Free tier eligible, general purpose, burstable performance
  • m5.large - General purpose, balanced compute/memory
  • c5.large - Compute optimized for CPU-intensive workloads
  • r5.large - Memory optimized for memory-intensive workloads
  • d2.xlarge - Storage optimized for high disk throughput

⚡ AWS Compute Optimizer

AWS Compute Optimizer is a service that analyzes the configuration and utilization metrics of your AWS resources to provide recommendations for optimizing performance and cost.

Key Benefits:

  • Identifies under-provisioned resources that might cause poor application performance
  • Identifies over-provisioned resources that may lead to unnecessary infrastructure costs
  • Provides specific instance type recommendations with projected performance risk and cost impact

How Compute Optimizer Works with EC2:

  1. Analyzes EC2 instance specifications and CloudWatch metrics
  2. Identifies patterns in resource usage using machine learning
  3. Generates recommendations for right-sizing your instances
  4. Provides projected utilization metrics for recommended instances

Exam Tip:

For questions about optimizing EC2 costs or performance, remember that AWS Compute Optimizer:

  • Uses at least 14 days of metric data to make recommendations
  • Supports EC2 instances, Auto Scaling groups, EBS volumes, Lambda functions, and more
  • Is a free service available to all AWS customers
  • Helps determine if your instances are the right size (neither over nor under-provisioned)

📝 Practice Questions

  1. Your company runs a critical application that needs to be available 24/7 and requires consistent performance. The workload is steady and predictable for the next 3 years. Which EC2 purchasing option is most cost-effective?

    Answer: Reserved Instances (3-year term)

  2. You're running a non-critical data processing job that can be interrupted. You want to minimize costs. Which EC2 purchasing option should you choose?

    Answer: Spot Instances

  3. Which AWS service would help you identify if your EC2 instances are over or under-provisioned?

    Answer: AWS Compute Optimizer

  4. You have software with licensing that's tied to the physical CPU cores. Which EC2 option is best suited for this requirement?

    Answer: Dedicated Hosts

  5. Which EC2 instance family would be most appropriate for a high-performance database with large memory requirements?

    Answer: Memory Optimized (R family)

🔑 Key Takeaways

  1. EC2 provides resizable compute capacity in the cloud - virtual servers on-demand
  2. Purchase options (SORD): Spot, On-Demand, Reserved, Dedicated - each has specific use cases
  3. Instance families serve different workload needs (FIGHT DR MC PX)
  4. EC2 integrates with many AWS services to create complete solutions
  5. AWS Compute Optimizer helps ensure your instances are correctly sized
