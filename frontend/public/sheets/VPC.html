AWS VPC Services Cheatsheet

For AWS Certified Cloud Practitioner Exam

Core VPC Concepts

Virtual Private Cloud

Your own isolated section of the AWS cloud where you launch AWS resources.
Think of a VPC as your own private data center in the AWS cloud.
✓ Remember: VPC = Virtual Private Cloudspace

Subnets

Network partitions of the VPC that are tied to an Availability Zone.
Subnets can be public (with internet access) or private (internal only).
✓ Remember: One Subnet = One AZ (never spans multiple AZs)

Internet Gateway

Provides internet access to resources in your VPC.
Attached at the VPC level, not to individual subnets.
✓ Remember: The Door to the Internet

NAT Gateway / Instances

Gives private subnets access to the internet without allowing inbound connections.
One-way door: Outbound traffic only.
✓ Remember: NAT = "Need Access To" internet for private resources

Security Components

Network ACLs

Stateless firewall that operates at the subnet level.
Must configure separate rules for inbound AND outbound traffic.
✓ Remember: NACL = No Auto Connection Return Logic (stateless)

Security Groups

Stateful firewall that operates at the instance level or ENI.
Return traffic is automatically allowed regardless of outbound rules.
✓ Remember: Security Groups Remember (stateful)

VPC Connectivity Options

VPC Peering

Connect two VPCs with non-overlapping IP ranges.
Non-transitive (A connected to B and B to C doesn't mean A connects to C).
✓ Remember: Peers Don't Share Friends (non-transitive)

Elastic IP

Fixed public IPv4 address that can be associated with an instance or ENI.
Costs money when not in use.
✓ Remember: "Elastic = Expensive" when idle

VPC Endpoints

Provide private access to AWS services within a VPC.
No need for internet gateway or NAT; stays within AWS network.
✓ Remember: "Private Path to AWS Services"

PrivateLink

Privately connect to services in a 3rd party VPC.
Secure way to consume services across VPC boundaries.
✓ Remember: "Secret Tunnel to Partner Services"

Hybrid Connectivity & Monitoring

VPC Flow Logs

Capture network traffic information for your VPC.
Helps with troubleshooting and security monitoring.
✓ Remember: "Network Traffic Diary"

Site-to-Site VPN

VPN connection over public internet between on-premises DC and AWS.
Encrypted tunnel but subject to internet performance.
✓ Remember: "Public Internet Tunnel"

Client VPN

OpenVPN connection from your computer into your VPC.
Secure remote access for employees.
✓ Remember: "WFH Access" (Work From Home)

Direct Connect

Direct private connection to AWS.
More reliable, faster, and lower latency than internet-based connections.
✓ Remember: "Private Highway to AWS" (no internet)

Transit Gateway

Connect thousands of VPCs and on-premises networks together.
Acts as a central hub for network traffic.
✓ Remember: "Network Hub for Everything" (star topology)

Exam Tips

Key Comparisons

  • Security Groups vs NACLs: Stateful vs Stateless
  • Internet Gateway vs NAT Gateway: Public access vs Private outbound
  • VPC Peering vs Transit Gateway: Direct connection vs Hub-and-spoke
  • Direct Connect vs Site-to-Site VPN: Private dedicated vs Public internet

Exam Focus Areas

  • Know when to use each connectivity option
  • Understand cost implications (e.g., Elastic IP when not in use)
  • Recognize security best practices for VPC design
  • Remember limitations of each service (e.g., VPC Peering being non-transitive)
