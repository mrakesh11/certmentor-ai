AWS Monitoring Services - CCP Exam Cheatsheet

CW
CloudWatch

AWS's primary monitoring and observability service that provides data and insights for AWS resources and applications.

  • Metrics: Monitor performance of AWS services and billing metrics
  • Alarms: Automate notifications, perform EC2 actions, notify SNS based on metrics
  • Logs: Collect log files from EC2 instances, servers, Lambda functions
  • Events/EventBridge: React to AWS events or trigger rules on a schedule
🧠 Memory Tip: Think "MALE" - Metrics, Alarms, Logs, Events - the four core components of CloudWatch

CT
CloudTrail

Service that enables governance, compliance, and audit of your AWS account.

  • API Tracking: Records API calls made within your AWS account
  • CloudTrail Insights: Automated analysis of CloudTrail events to identify unusual activity
🧠 Memory Tip: CloudTRAIL leaves a "trail" of all API activities - think of it as your AWS account's security camera footage

XR
X-Ray

Service that helps developers analyze and debug distributed applications.

  • Trace Requests: Track requests made through distributed applications
  • Performance Analysis: Identify bottlenecks and troubleshoot issues
🧠 Memory Tip: X-Ray lets you see "through" your application like an X-ray sees through your body - revealing the internal structure

HD
AWS Health Dashboard

Provides visibility into resource performance and availability of AWS services.

  • Service Health: Status of all AWS services across all regions
  • Account Health Dashboard: AWS events that impact your infrastructure
🧠 Memory Tip: Two levels of health - "general" service health (for everyone) and "your specific" account health

CG
Amazon CodeGuru

Developer tool that provides intelligent recommendations for improving code quality.

  • Automated Code Reviews: Identifies critical issues, security vulnerabilities, and hard-to-find bugs
  • Performance Recommendations: Suggests ways to improve application performance
🧠 Memory Tip: Your code's "guru" (expert advisor) - it's like having an AI code mentor
