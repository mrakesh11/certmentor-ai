AWS Deployment Services Cheatsheet

CCP Exam Quick Reference Guide

Deployment Services Overview

CF
CloudFormation

  • Infrastructure as Code service
  • AWS-only resource management
  • Deploy entire infrastructures with templates
  • Can be repeated across Regions & Accounts
  • Templates written in YAML or JSON
Remember: CloudFormation = Create Full infrastructure from code

EB
Elastic Beanstalk

  • Platform as a Service (PaaS) solution
  • AWS-only managed service
  • Limited to specific languages or Docker
  • Consistent deployment with predefined architectures
  • Example: ALB + EC2 + RDS
Remember: EB = Easy Button for deploying applications

CD
CodeDeploy

  • Hybrid deployment service
  • Deploy & upgrade applications on servers
  • Works with EC2, on-premises servers
  • Automates application deployment & updates
  • Minimizes downtime during deployment
Remember: CodeDeploy = Continuously Distribute applications

SM
Systems Manager

  • Hybrid management service
  • Patch, configure, run commands at scale
  • Manage EC2 and on-premises resources
  • Provides operational insights
  • Helps maintain security & compliance
Remember: Systems Manager = Servers Management in bulk

Mnemonic: The CI/CD pipeline follows the "CBDP" order: Commit → Build → Deploy → Production

CC
CodeCommit

  • Private Git repository service
  • Fully managed source control service
  • Provides version control
  • Integrated with other AWS services
  • Secure & highly available
Remember: CodeCommit = Central Code storage

CB
CodeBuild

  • Fully managed build service
  • Compiles code, runs tests, produces packages
  • Runs in scalable containers
  • No build servers to manage
  • Pay only for compute time used
Remember: CodeBuild = Compile & Build in the cloud

CP
CodePipeline

  • Continuous delivery service
  • Orchestrates the entire release process
  • Automates build, test, deployment stages
  • Integrates with AWS & third-party tools
  • Visualizes workflow stages
Remember: CodePipeline = Connects the Pieces together

CA
CodeArtifact

  • Artifact repository service
  • Store & share software packages
  • Manages code dependencies
  • Works with common package managers
  • Secure & scalable
Remember: CodeArtifact = Code Assets storage

CDK
AWS CDK

  • Cloud Development Kit
  • Define infrastructure using programming languages
  • Supports TypeScript, Python, Java & more
  • Creates CloudFormation templates
  • Enables infrastructure as actual code
Remember: CDK = Code Defines Kloud resources

Key Comparisons for CCP Exam

Deployment Tools Comparison:
  • CloudFormation = Complete infrastructure as code (servers, databases, networks)
  • Elastic Beanstalk = Platform as a service for developers (uploads code, AWS handles the rest)
  • CodeDeploy = Application deployment to existing servers
  • Systems Manager = Manage and configure existing servers
Developer Tools Memory Device: "CCBDPA"
  • CodeCommit: Store code (Git)
  • CodeBuild: Build & test code
  • CodeDeploy: Deploy code to servers
  • CodePipeline: Automate the entire process
  • CodeArtifact: Store dependencies
  • AWS CDK: Define infrastructure with programming languages
✅ AWS Systems Manager → The Boss, manages AWS resources. ✅ SSM Session Manager → The Remote Control, lets you securely connect to servers. ✅ SSM Parameter Store → The Secret Keeper, safely stores sensitive info.
