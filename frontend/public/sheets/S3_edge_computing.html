S3 Basics

Amazon S3 (Simple Storage Service) is an object storage service offering industry-leading scalability, availability, security, and performance.

Buckets vs Objects:

  • Bucket: Container for objects, requires globally unique name, tied to a specific region
  • Object: File + metadata, identified by a key (file path)
  • Max object size: 5TB
  • Must use Multi-part upload for files >5GB

Security Features

  • IAM Policies: Controls which users/roles can access buckets/objects
  • Bucket Policies: JSON-based policies attached to buckets for cross-account access
  • Block Public Access: Additional layer to prevent public access
  • S3 Encryption:
    • Server-Side Encryption (SSE): SSE-S3, SSE-KMS, SSE-C
    • Client-Side Encryption

Core Features

W S3 Website Hosting

  • Host static websites
  • URL format: http://bucket-name.s3-website-region.amazonaws.com
  • Requires public read access on objects

V S3 Versioning

  • Keep multiple versions of objects
  • Protects against accidental deletions
  • Can't be disabled once enabled (only suspended)
  • Integrates with lifecycle rules

R S3 Replication

  • Cross-Region Replication (CRR)
  • Same-Region Replication (SRR)
  • Requires versioning enabled on source & destination
  • Not retroactive for existing objects

S3 Storage Classes

Choose the right storage class based on access patterns, durability, and cost.

Storage Class Use Case Key Characteristics
S3 Standard Frequently accessed data 99.99% availability, low latency, high throughput
S3 Intelligent-Tiering Unknown or changing access patterns Automatic cost optimization, monthly monitoring fee
S3 Standard-IA (Infrequent Access) Long-lived, less frequently accessed data Lower cost than Standard, retrieval fee, minimum 30-day storage
S3 One Zone-IA Non-critical, infrequently accessed data Single AZ storage (99.5% availability), cheaper than Standard-IA
S3 Glacier Instant Retrieval Archived data needing immediate access Millisecond retrieval, minimum 90-day storage
S3 Glacier Flexible Retrieval Archived data (no immediate need) Retrieval options: Expedited (1-5 min), Standard (3-5 hrs), Bulk (5-12 hrs)
S3 Glacier Deep Archive Long-term archival, rarely accessed Lowest cost, retrieval time: Standard (12 hrs), Bulk (48 hrs)

Exam tip: Remember the durability across all storage classes is 99.999999999% (11 9's)

Snow Family

Physical devices for data migration and edge computing.

Device Storage Capacity Use Case
Snowcone 8 TB Small-scale data transfer, edge computing
Snowball Edge Up to 80 TB Large data transfer, rugged conditions, local processing
Snowmobile Up to 100 PB Exabyte-scale data transfer (shipping container)

OpsHub: Desktop application to manage Snow Family devices without command-line knowledge

Storage Gateway

Hybrid storage service that enables on-premises applications to use AWS cloud storage.

Type Function
File Gateway NFS/SMB interface to store files as S3 objects
Volume Gateway iSCSI interface for block storage backed by S3
Tape Gateway Virtual tape library backed by S3 and Glacier

S3 Advanced Features

  • Lifecycle Rules: Automate transitioning objects between storage classes or expiring objects
  • S3 Object Lock: Write-once-read-many (WORM) model
  • S3 Access Points: Dedicated access points for managing data access at scale
  • S3 Batch Operations: Perform operations on millions of objects with a single request

Key Exam Concepts:

  • S3 offers unlimited storage with individual objects up to 5TB
  • Bucket names must be globally unique (across all AWS accounts)
  • Data consistency model: strong read-after-write consistency
  • S3 can be accessed via console, CLI, SDK, and REST API
  • S3 URLs: https://bucket-name.s3.region.amazonaws.com/key
